# Werdy's Kitchen - Information Systems Technology Audit

Repository ini berisi dokumentasi dan berkas laporan audit teknologi sistem informasi untuk **Werdy's Kitchen**.

---

## ?? Daftar Berkas / Deliverables

| Dokumen | Deskripsi | Tipe Berkas |
| :--- | :--- | :---: |
| **[INFORMATION SYSTEMS TECHNOLOGY AUDIT REPORT.pdf](./INFORMATION%20SYSTEMS%20TECHNOLOGY%20AUDIT%20REPORT.pdf)** | Laporan utama audit teknologi sistem informasi yang mencakup evaluasi, temuan audit, analisis risiko, serta rekomendasi perbaikan sistem. | PDF |
| **[EVIDENCE COLLECTION.pdf](./EVIDENCE%20COLLECTION.pdf)** | Kumpulan bukti audit (*Evidence Collection*) yang mendukung temuan dan validasi proses operasional/teknologi sistem informasi. | PDF |

---

## ?? Ruang Lingkup Audit
- Evaluasi infrastruktur teknologi dan sistem informasi yang digunakan oleh Werdy's Kitchen.
- Pengujian kontrol keamanan, integritas data, dan ketersediaan layanan.
- Pengumpulan bukti audit (*audit evidence*) untuk memastikan kepatuhan terhadap standar operasional.
- Penyusunan rekomendasi perbaikan untuk mitigasi risiko teknologi.
